Kept from legacy, because it works: Cloudflare Turnstile on sign-in, create-account and forgot-password, with the submit button gated until the check passes and the token cleared on expiry — legacy already does exactly this. The one change is the failure path: an expired token becomes a line under the widget instead of a toast, so it is still on screen when you look back at the form. Google and Facebook are the two providers the account system actually supports (/api/auth/google, /api/auth/facebook).

What I still need agreed before building: the endpoint contract. V5's backend is a separate repo, so these screens name the fields and the states they can be in — needs 2FA, needs verification, locked, bad credentials — and the API shape should be agreed rather than assumed. Also whether verification is enforced (my recommendation) or dropped.
