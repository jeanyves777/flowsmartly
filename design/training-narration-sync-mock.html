The Standard LLM Architecture

  • User prompt in, tokens out
  • No feedback loop — the output is final, there is no revision pass once it’s generated
  • Context window is the only memory
  • Nothing is learned from the outcome, so every session starts cold with no recall of the last

Ticks mark where each bullet reveals. In content-aware mode a long point earns a longer slice, so the reveal lands as the narrator reaches it. The marker pill + underline ride the current point.
