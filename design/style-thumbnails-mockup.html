Video-type & animated looks get a real generated sample

Cards flagged ▶ sample represent motion. For these we generate a few-second real clip per style once (via our video providers), host it, and play it muted on hover — so a user sees actual footage of the look, not a still. Static looks (website, editorial, résumé) ship as the rendered previews above with no generation cost.

Step 1 · now
Shared StyleThumb component

One `<StyleThumb kind style />` with a small registry of CSS previews per option — drops into every brief's option cards. No backend change; the selected value is untouched.

Step 2
Wire every selector

Video type, website/store styles, portfolio templates, avatar quality, design styles (already carry a `bg`), voice presets. One row each, consistent across studios.

Step 3
Real video samples

Generate + host a few-second clip per motion style; swap the still preview for a muted hover-play. Cached once, reused for everyone.
