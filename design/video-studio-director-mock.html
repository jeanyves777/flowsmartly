Video Studio — Director: one canvas for AI, Avatar & Reel

Reel + Avatar + Video studios fuse into a single pipeline playground. One master brief (with media upload) → a director agent drafts a sequence of scene nodes, each rendered by whichever engine fits (AI cinematic, your talking-avatar clone, or scored reel clips) — then combined into one film. A docked timeline from the classic editor gives live multi-track editing. Backends stay as-is; the new piece is one unified canvas + a video-director agent skill. Use the tabs and click nodes to explore.

The only new code is this one canvas + a video-director agent skill that reads/writes the pipeline.
