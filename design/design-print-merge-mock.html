What this changes
  • Screen ⇄ Print toggle in the Design Studio header — the only new control.
  • Print reads as the same surface — header says “Design Studio”, the Create rail item stays highlighted (no separate Print destination).
  • Each mode keeps its own document + autosave, so toggling never converts or loses your work.
  • The agent’s start_print_project now flips into Print mode on its own when you’re in Screen mode.
